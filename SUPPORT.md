# Support

| Kind | Where |
| --- | --- |
| Bug | [Bug report](https://github.com/francescoveryra-dot/IAF-Agent-Bridge/issues/new?template=bug_report.yml) |
| Feature request | [Feature request](https://github.com/francescoveryra-dot/IAF-Agent-Bridge/issues/new?template=feature_request.yml) |
| Security vulnerability | [Private advisory](https://github.com/francescoveryra-dot/IAF-Agent-Bridge/security/advisories/new) |
| Question about install or use | A normal issue, after you have read [docs/troubleshooting.md](docs/troubleshooting.md) |

Do not put tokens, passwords, or private keys in any of these.

There is no guaranteed response time.
