# Changelog

## 1.0.0

Initial release of IAF Agent Bridge.

- Stdio MCP server with `delegate`, `cancel`, and `doctor`.
- Cursor Agent executor over ACP, including session create/load, streaming updates, permissions, cancellation, and Cursor's blocking plan and question methods.
- Autonomous permission policy that keeps ordinary development moving and rejects destructive operations.
- Supervisor skill for the natural continue / complete / blocked loop on the same Cursor session.
